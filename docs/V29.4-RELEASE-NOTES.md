# V29.4 release notes

Source-only release. This repository distributes no APKs.

No APK is published for V29.4, and none will be: a patched keyboard contains
Google's Gboard code, which is not redistributable (see
[`LICENSING-AUDIT.md`](LICENSING-AUDIT.md)). V29.4 is the source at tag
`v29.4`, these notes and the provenance record
[`ledger/v29.4-provenance.md`](../ledger/v29.4-provenance.md).

## What changed

- **New maintainer signing key.** The key that signed the V29.3 test build is
  lost. Private test builds are now signed with a new maintainer key, signer
  certificate SHA-256
  `679cfdec6cef6ab17a9778cde4d3bbf3b8ccfe6ae2380d3da11679aae01e2e78`
  (replaces `085ecb290e3645bca6c3419faeb4f3f0d7a845fccb8621e3030cf87475990702`).
- **Key custody.** The maintainer key lives only in GitHub Actions secrets,
  plus an offline backup kept by the maintainer. It is never in the
  repository. A manual workflow, `maintainer-key-check.yml`, signs the
  synthetic fixture with it and checks the signer against the recorded
  fingerprint. It uploads no APK.
- **No behavior changes.** Voice, typing and paste conversion are unchanged
  from V29.3. Layouts, settings and known limits are as described in
  [`V29.3-RELEASE-NOTES.md`](V29.3-RELEASE-NOTES.md).

## Other changes

- Patcher fix: `dex_patch.py` counts an array parameter as one register slot,
  whatever its element type.
- CI: `ci.yml` runs the Python unit tests for the patcher helpers and the
  static suite on every push and pull request.
- Docs: README, architecture, user guide, releasing guide and docs index;
  code of conduct, contributing guide, PR and issue templates, CODEOWNERS and
  Dependabot.
- Project website (GitHub Pages), banner, brand sheet, icon showcase and
  favicon.
- Personal-looking emails in the v29.3 test fixtures replaced with
  `example.com` addresses.
- Temporary diagnostic probes and their workflows removed.
- GitHub Actions bumped: `actions/checkout` 7.0.1, `actions/upload-artifact`
  7.0.2.

## Tested

- Python unit tests and the static suite (fixture build, patch, fail-closed
  checks) pass on the tagged source; see [`RELEASING.md`](RELEASING.md) for the
  commands.
- No new device testing for this release. Maintainer test builds 245 to 253
  are listed separately in the changelog with their own evidence levels.

## Install (for builds you make yourself)

- A build signed with the new key cannot install over a V29.3 build. Uninstall
  the V29.3 build once first; later builds signed with the same new key update
  in place.
- Re-enable the keyboard and re-add your layouts after installing.
